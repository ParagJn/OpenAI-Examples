# PDD (Business Process Design Document Generator)

PDD (Business Process Design Document Generator) is an ultra-lightweight application designed to demonstrate the use of OpenAI's GPT-4 model for generating Business Process Design Documents (PDD) based on user inputs. 

In this example, the application generates documents for SAP functional areas and topics. Users can upload a document or an image, which is then processed to generate a design document. Additionally, the application creates a business process model and allows users to download the output in BPMN format, which can be further modified using BPMN editors.

## Files

### Generate_PDD.py
This is the main program file, this file needs streamlit to be installed on the system. When executed, the program runs locally on the browser window. 
All the other modules are required by this program. Each module has a specific function. 
To run the program, use the following command in the terminal:
```bash
streamlit run Generate_PDD.py
```

#### AzureAIConnection.py

This script handles the connection to Azure OpenAI services. It includes the following functionalities:

- **AzureAIConnection Class**: Manages the initialization and retrieval of the Azure OpenAI client.
- **AzureAIConnectionError Class**: Custom exception for handling Azure AI connection errors.

*Note: Ensure you have setup appropriate TPM for token management. Will require TPM > 10k

#### Environment Variables

The script requires the following environment variables to be set:

- `AZURE_OPENAI_VERSION`: The version of the Azure OpenAI API.
- `AZURE_OPENAI_KEY`: The API key for accessing Azure OpenAI services.
- `AZURE_OPENAI_BASE`: The base URL for the Azure OpenAI endpoint.
- `AZURE_OPENAI_DEPLOYMENT_NAME`: The deployment name for the Azure OpenAI model.

#### Llama Connector
This scripts handles the connection to llama model. This is used to validate the content generated by the Open AI model. 
Currently, this is disabled, and work is in progress. 

#### Prompt Generator
This script manages all the prompts that are passed to generate the content or to generate the improvements. 

#### Image Convertor
This script converts the uploaded image to markdown language that can used to pass it down to the model to generate the content. 
Requires LLM Model for this processing

#### Logging
The script uses a custom logger from `App_Logger`. Make sure to configure the logger as needed.

#### Sample Template
Use the provided document ```Document-Example-Template.docx``` to test the application function. As mentioned in the code and on the readme file, this example is currently setup for specific function areas under SAP and the sections of document are hard coded

Use the provided image ```image.png``` to test the application function using image upload feature.
